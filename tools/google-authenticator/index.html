Google Authenticator to Apple Passwords

Export the accounts you already have in Google Authenticator, then decode the QR screenshots into setup keys for Apple Passwords.

Local-only conversion: selected images and decoded keys stay in this browser. This page does not upload them.

What you need: A device that already has the Google Authenticator accounts you want to move, or a device where those accounts are synced. A fresh install cannot recreate missing codes.

Walkthrough

Export the accounts you already have

The first panel shows an existing Google Authenticator vault. The export path uses Google’s help instructions; the save and upload panels are illustrative, and none of these images are from your personal accounts.

Real conversion tool

Choose your export QR screenshots

On the old device, choose Menu, Transfer accounts, Export accounts, select the accounts, and tap Next. Save each QR screen as an image.

Handle the result as a secret. Anyone with a setup key can generate that account's verification codes. Do not use a screenshot with unrelated private content.

Choose every QR screenshot from the export. The browser merges exact duplicate accounts.

Choose one or more export QR screenshots.

Apple Passwords handoff

Add each setup key to the matching account

  1. Open the matching account in Apple Passwords.
  2. Choose Edit, then Set Up Code.
  3. Paste the setup key and choose Use Setup Key.
  4. Verify that Apple Passwords generates the current code before you remove the old entry.
