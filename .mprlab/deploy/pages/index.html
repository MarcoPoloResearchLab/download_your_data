Your exports stay on your Mac.

Download Your Data is one Apple Silicon application for inspecting personal exports, building a private conversation archive, and exploring Netflix viewing activity. The workspace and API run on loopback; there is no hosted personal-data service.

Download the latest release Read the first-run guide

What the release contains

  • One macOS arm64 executable with the browser workspace embedded.
  • First-run, LM Studio, backup, replacement, and deletion guidance.
  • A SHA-256 checksum published beside the application archive.

The privacy boundary

Archives, databases, vectors, reports, and caches live only in the owner-selected private data root. Optional TMDB enrichment happens only after explicit initiation and sends derived title queries, not source CSV rows or viewing dates.
