Password merger

Add CSV exports, select conflicting passwords, and download one merged file.

Files stay in this browser. No credentials are sent to servers.

1. Add password exports

Select one or more CSV files per source. Export guides are below.

Choose CSV files, then select Merge files.

    CSV files contain plaintext secrets. Keep exports and the final CSV private.

    2. Select each password to keep

    Export dates do not prove which password is newest. Distinct subdomains and usernames remain separate accounts.

    CSV contents and limits

    Your original credentials and application settings stay unchanged. This page does not operate your password manager.

    Safari uses the Passwords app on current macOS. This tool accepts password CSV files, not Safari ZIP archives.

    The final fields are name,url,username,password,note.

    Anyone with access to the file can read its passwords and verification code setup data.

    • Accounts with only empty passwords stay in the result. Some destinations can reject empty usernames or passwords.
    • The result keeps notes and other saved URLs in the note field. Destination imports can omit these notes.
    • Verification code setup URI (import separately): supplied setup URIs stay in notes. CSV import does not install verification codes.
    • Passkeys, shared items, and other records absent from the CSV need separate handling.

    After import, examine the destination records. Keep necessary backups until you verify the result. Then remove unnecessary plaintext files.

    Export from each application
    Chrome export
    1. Open Google Password Manager from Chrome.
    2. Select Settings.
    3. Under Export Passwords, select Download file.
    4. Save the CSV.
    Chrome export help
    Vivaldi export
    1. From the Vivaldi menu, select File > Export > Export Passwords.
    2. Complete the requested authentication.
    3. Save the CSV.
    Vivaldi password help
    Firefox export
    1. Open Passwords from the Firefox menu.
    2. Open the three-dot menu.
    3. Select Export Passwords….
    4. Select Continue with export.
    5. Complete the requested authentication.
    6. Save the CSV.
    Firefox export help
    Safari export

    Current Safari uses Passwords for password export.

    1. Open Passwords on your Mac.
    2. Use the Apple Passwords export instructions below.
    3. Select the resulting CSV in the Safari file picker above.
    Safari password guidance
    Apple Passwords export
    1. Open Passwords on your Mac.
    2. Select File > Export All Passwords to File.
    3. Select Export Passwords.
    4. Save the CSV.

    Apple excludes some records, such as Wi-Fi passwords and some shared passwords.

    Apple export help

    Import the final CSV
    Chrome import
    1. Open Google Password Manager in Chrome.
    2. Select Settings.
    3. Under Import passwords, select Select file.
    4. Select the final CSV.
    5. Complete the import prompts.

    Chrome accepts up to 3,000 passwords per import.

    Chrome import help
    Vivaldi import
    1. Open vivaldi:password-manager/settings in Vivaldi.
    2. Under Import passwords, select Select file.
    3. Select the final CSV.
    4. Select Open.
    Vivaldi import help
    Firefox import
    1. Open Passwords from the Firefox menu.
    2. Open the three-dot menu.
    3. Select Import from a File….
    4. Select the final CSV.
    5. Select Open.
    6. Select Done after the import.
    Firefox import help

    1. Open Passwords on your Mac.

    Apple Passwords import
    1. Open Passwords on your Mac.
    2. Select File > Import Passwords from File.
    3. Select Choose File.
    4. Select the final CSV.
    5. Select Import.
    6. Examine any records that Apple cannot import.

    Apple Passwords does not replace existing passwords during CSV import.

    Apple import help

    Optional: replace Apple website passwords

    Normal CSV import keeps existing Apple passwords. Replacement requires manual removal of the website passwords you intend to replace.

    This page does not remove passwords. Apple removal also affects iCloud Keychain. The All category can contain passkeys.

    1. Export the Apple website passwords you want to keep.
    2. Keep the Apple CSV as a separate backup.
    3. Select the backup under Apple Passwords above.
    4. Select Merge files.
    5. If conflicts appear, select one candidate per account under Select each password to keep.
    6. When enabled, select Download merged CSV.
    7. Handle excluded passkeys, shared items, and verification codes separately.

    The merger shows each candidate and its source. Download stays unavailable until every conflicting account has a selected password.

    Manual replacement steps

    1. Open Passwords on your Mac.
    2. Select All.
    3. Select only a website password account present in your backup and final CSV.
    4. Make sure that the account is a website password, not a passkey or excluded record.
    5. Select Edit.
    6. Select Delete Password.
    7. In the confirmation, select Delete Password again.
    8. Repeat for each website password you intend to replace.
    9. Use the Apple import instructions above to import the final CSV once.
    10. Examine the imported records before you remove plaintext files.
