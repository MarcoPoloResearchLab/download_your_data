How to Export a WhatsApp Chat or Account Report

A WhatsApp chat export and a WhatsApp account-information report are different files. Use the account report for account metadata, or export each individual or group chat when you need message history.

The decision that matters

Choose the right export before you start

Request account info does not include personal messages, while Export chat does not create a restorable WhatsApp backup. Choosing the correct workflow before you start prevents an incomplete or unusable result.

Current workflow

How to complete the current provider export

  1. 1

    For account information and settings, open WhatsApp on your primary device and go to Settings → Account → Request account info.

    Open the first-party step ↗
  2. 2

    Tap Request report. WhatsApp says the report is typically ready in three days.

    Open the first-party step ↗
  3. 3

    When notified, return to Request account info and tap Download report; the ZIP contains HTML and JSON files.

    Open the first-party step ↗
  4. 4

    Tap Export report, choose a private destination, and store the report carefully.

    Open the first-party step ↗
  5. 5

    The account-information report does not include personal messages. To save messages, open the individual or group chat you need.

    Open the first-party step ↗
  6. 6

    On Android, tap More options → More → Export chat. On iPhone, open the chat details and select Export Chat.

    Open the first-party step ↗
  7. 7

    Choose Without media or Include media, then select where to save it. The exported text file is not a WhatsApp backup and cannot be re-imported.

    Open the first-party step ↗

What this workflow covers

Useful output and next steps

  • Requesting the account-information report from Settings and Account
  • Downloading and privately storing the report when WhatsApp marks it ready
  • Exporting one individual or group chat with or without media

Objections and limits

What this resource does not promise

  • The account-information report does not include personal messages.
  • Chats are exported individually rather than as one account-wide message archive.
  • The exported text file is not a WhatsApp backup and cannot be re-imported.

Questions before you export

Frequently asked questions

Does the WhatsApp account report include messages?

No. Request account info covers account information and settings, not personal messages.

Can I export every WhatsApp chat at once?

The current guide exports the individual or group chat you open. Repeat the workflow for each chat you need.

Can a WhatsApp chat export be restored into WhatsApp?

No. The exported text file is a saved copy, not a WhatsApp backup and not a re-import format.
