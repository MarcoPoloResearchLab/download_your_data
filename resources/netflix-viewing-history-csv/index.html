How to Download Your Netflix Viewing History CSV

A Netflix viewing history CSV is the smallest useful export for reviewing what one profile watched and when. Netflix provides it from Viewing activity, not from the separate full-account information archive.

Open the visual Netflix export guide See the workflow

Quick verdict

Best for
People who need a dated viewing list for one Netflix profile
Required input
Access to the Netflix profile and its Viewing activity page
Product fit
The downloaded Title and Date CSV is the supported Netflix workspace input

The decision that matters

Choose the right export before you start

Netflix offers more than one data-download path. The Download Your Data workspace intentionally accepts only the per-profile Viewing activity CSV, so choosing the full personal-information archive creates the wrong input and adds unnecessary sensitive data.

    Open Netflix in a browser and go to Account.

What this workflow covers

Useful output and next steps

  • A Title column containing the displayed movie, series, season, or episode name
  • A Date column for each viewing-activity row
  • One profile at a time, matching the profile selected before opening Viewing activity

Objections and limits

What this resource does not promise

  • The file is not the full Netflix personal-information archive.
  • Profiles must be downloaded separately when you need more than one profile.
  • The base CSV does not include TMDB genres, runtimes, ratings, or production metadata.

Questions before you export

Frequently asked questions

Which Netflix file does Download Your Data accept?

It accepts the per-profile Viewing activity CSV downloaded with Download all. It does not accept the separate full-account personal-information archive as the same input.

Does the Netflix CSV include every profile?

No. The workflow starts from a selected profile, so download each profile's Viewing activity separately when you need multiple histories.

What columns should the Netflix viewing history CSV contain?

The current supported file has the header Title,Date and one viewing-activity row beneath it for each displayed title and date.
